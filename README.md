# Stopwatch & Timer

A modern and responsive Stopwatch & Timer web application built with Vanilla JavaScript, featuring accurate time calculations, lap tracking, countdown functionality, keyboard shortcuts, and mobile swipe navigation.

Designed with a clean dark UI and smooth interactions to demonstrate strong fundamentals in DOM manipulation, state management, and responsive frontend development.

## Features

### Stopwatch

- Start, pause, resume, and reset functionality
- Accurate time tracking using Date.now()
- Lap recording system
- Individual lap difference calculation

### Timer

- Custom countdown timer
- Input validation with automatic overflow conversion
- Pause and resume support
- Audio alert when countdown finishes

### User Experience

- Fully responsive design
- Mobile swipe navigation between screens
- Keyboard shortcuts support
- Smooth transitions and interactive UI feedback
- Clean dark-themed interface


## Tech Stack

- HTML
- CSS
- Javascript(vanilla)

## Keyboard Shortcuts

| Key | Action |
|------|--------|
| `Space` | Start / Pause |
| `Escape` | Reset |
| `Enter` | Create Lap (Stopwatch) |
| `← / →` | Switch between Stopwatch & Timer |

## How to Run

1. Clone the repo
2. Simply open `index.html` in your browser
